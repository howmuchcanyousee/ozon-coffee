# Ozon Coffee

Учебное мобильное приложение кофейни на React Native, Expo SDK 57 и TypeScript. Данные сохраняются локально в SQLite.

## Возможности

- Каталог: 12 товаров, 5 категорий, поиск и популярные позиции.
- Корзина: изменение количества, удаление, пересчёт суммы и сохранение между запусками.
- Оформление и история заказов.
- Регистрация, вход и отдельные данные аккаунтов.
- Бронирование столиков с проверкой занятости и отменой.
- Статистика с векторными диаграммами.

Заказы и бронирования учебные: сохраняются на устройстве, оплата не списывается. Аккаунты не синхронизируются между устройствами. Проверена Android-версия; iOS-сборка не проверялась.

## Запуск и сборка

Нужны Node.js 24, JDK 17 и Android SDK. Установите зависимости:

```powershell
npm ci
```

Для сборки Android APK настройте JAVA_HOME и ANDROID_HOME и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-android.ps1
```

Результат: `build/Ozon-Coffee.apk` для arm64-v8a и x86_64. Сборка предназначена для учебного использования и использует стандартную подпись шаблона Android; для публикации в магазине настройте собственную подпись.

После подключения Android-устройства или запуска эмулятора:

```powershell
adb install -r build/Ozon-Coffee.apk
adb shell am start -n com.maratique.coffeehouse/.MainActivity
```

При добавлении нативных модулей нужна новая APK. Expo Go не включает используемую нативную библиотеку обработки паролей.

## Проверки

```powershell
npm run typecheck
npm run lint
npm test
npx expo-doctor
```

18 тестов проверяют корзину, транзакционное оформление, аккаунты, миграцию, бронирования и статистику. Тесты используют временные копии базы.

## Структура

- `src/app` — экраны и маршруты Expo Router.
- `src/components` — общие элементы интерфейса.
- `src/store` — состояние приложения.
- `src/data` — операции SQLite и бизнес-логика.
- `assets` — изображения и исходная демонстрационная база.
- `tests` — автоматические проверки.

В репозитории размещается программа. Отчёты, учебные документы, SDK, кэши и пользовательская база эмулятора не включены.
